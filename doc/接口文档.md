# TextCNN 分类与错题管理接口文档

## 1. 概述

- 服务名称：TextCNN Classification API
- 版本：v1
- 基础地址（本地默认）：http://127.0.0.1:8000
- 版本前缀：/api/v1
- 数据格式：application/json
- 字符编码：UTF-8

## 2. 统一返回结构

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

- code：业务状态码，0 表示成功，非 0 表示失败
- message：提示信息
- data：业务数据（失败时通常为 null）

## 3. 状态码约定

- 200：请求成功（code=0）
- 400：业务参数错误（如标签非法、状态非法）
- 404：资源不存在（如 question_id 不存在）
- 422：参数校验失败
- 500：服务器内部错误

## 4. 接口列表（v1）

## 4.1 健康检查

- 方法：GET
- 路径：/api/v1/health

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "status": "ok",
    "version": "v1"
  }
}
```

## 4.2 标签列表

- 方法：GET
- 路径：/api/v1/labels

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "labels": [
      "computer_architecture",
      "computer_network",
      "data_structure",
      "operating_system"
    ]
  }
}
```

## 4.3 AI 分类（仅预测，不落库）

- 方法：POST
- 路径：/api/v1/ai/classify
- 请求体：

```json
{
  "text": "简述进程与线程的区别"
}
```

- 成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "label": "operating_system",
    "confidence": 0.97,
    "model_version": "textcnn-v1"
  }
}
```

## 4.4 保存错题

- 方法：POST
- 路径：/api/v1/questions
- 请求体：

```json
{
  "user_id": "demo_user",
  "stem": "简述进程与线程的区别",
  "options": ["A...", "B..."],
  "correct_answer": "A",
  "analysis": "线程共享进程资源...",
  "ai_label": "operating_system",
  "final_label": "operating_system",
  "confidence": 0.97,
  "source_type": "manual"
}
```

- 成功响应：

```json
{
  "code": 0,
  "message": "保存成功",
  "data": {
    "id": "q_xxx"
  }
}
```

## 4.5 分页查询错题

- 方法：GET
- 路径：/api/v1/questions
- 查询参数：
- page（默认 1）
- size（默认 20，最大 100）
- user_id（默认 demo_user）
- final_label（可选）
- mastery_status（可选）
- keyword（可选，匹配 stem）
- start_date（可选，ISO 日期或时间）
- end_date（可选，ISO 日期或时间）

- 成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "items": [
      {
        "id": "q_xxx",
        "user_id": "demo_user",
        "stem": "简述进程与线程的区别",
        "options": ["A...", "B..."],
        "correct_answer": "A",
        "analysis": "...",
        "ai_label": "operating_system",
        "final_label": "operating_system",
        "confidence": 0.97,
        "mastery_status": "unreviewed",
        "source_type": "manual",
        "created_at": "2026-04-12 21:00:00",
        "updated_at": "2026-04-12 21:00:00"
      }
    ],
    "total": 1,
    "page": 1,
    "size": 20
  }
}
```

## 4.6 更新掌握状态并写日志

- 方法：PATCH
- 路径：/api/v1/questions/{id}/status
- 请求体：

```json
{
  "user_id": "demo_user",
  "to_status": "reviewed"
}
```

- 成功响应：

```json
{
  "code": 0,
  "message": "状态更新成功",
  "data": {
    "id": "q_xxx",
    "to_status": "reviewed"
  }
}
```

## 4.7 人工改类反馈与增量语料任务

- 方法：POST
- 路径：/api/v1/ai/feedback
- 请求体：

```json
{
  "question_id": "q_xxx",
  "user_id": "demo_user",
  "question_text": "简述进程与线程的区别",
  "predicted_label": "computer_network",
  "corrected_label": "operating_system"
}
```

- 成功响应：

```json
{
  "code": 0,
  "message": "反馈已记录",
  "data": {
    "feedback_id": "fb_xxx"
  }
}
```

## 4.8 看板：学科分布

- 方法：GET
- 路径：/api/v1/dashboard/subject-distribution
- 查询参数：
- user_id（默认 demo_user）

- 成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "labels": ["operating_system", "data_structure"],
    "counts": [10, 7],
    "total": 17
  }
}
```

## 5. 枚举约定

- role：student | admin
- mastery_status：unreviewed | reviewed | mastered | careless
- source_type：manual | import | ocr
- write_status：pending | written | failed

## 6. 兼容接口（建议仅保留旧前端）

- GET /health
- GET /predict?text=...
- POST /predict
- POST /api/v1/predict

新接入建议统一使用 /api/v1/ai/classify。
