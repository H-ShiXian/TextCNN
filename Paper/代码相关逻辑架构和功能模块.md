**整体技术架构**
该项目是一个“模型训练 + 推理服务 + 业务系统 + 前端页面”的一体化文本分类系统，主线是：

数据准备 -> 词表/标签构建 -> TextCNN 训练 -> 离线评估 -> 在线推理 -> 题库业务闭环（反馈增量入库）

可按四层理解：

1. 算法与训练层  
- 使用 PyTorch 实现 TextCNN 分类模型，卷积核尺寸为 2/3/4，多通道卷积后池化拼接，再全连接分类。见 textcnn_model.py  
- 训练流程由 train.py 组织：读取数据、构建 DataLoader、训练、按验证集最优保存权重、再在测试集评估。  
- 统一参数配置在 config.py，包括路径、超参数、文本预处理函数。  

2. 数据处理层  
- 原始训练数据读取、分词、padding/截断、标签映射等在 config.py 与 vocab_built.py。  
- 词表和标签映射由 vocab_built.py 从训练集构建，产物为 data 下的 vocab.json 和 label.json。  
- 数据生成与格式转换辅助脚本位于 generate_408_dataset.py、export_json_to_traintxt.py。  

3. 推理与服务层  
- 统一推理封装在 inference.py 的 TextClassifier，提供 predict 与 predict_proba。  
- 后端主入口为 app.py，采用 FastAPI，提供分类、OCR、解析、题目管理、统计看板、管理员模型版本管理等接口；并用 SQLite 持久化业务数据。  
- 兼容命令行推理脚本在 predict.py。  

4. 表现与验证层  
- 前端静态页面与交互脚本在 index.html、app.js、login.html、login.js、style.css。  
- 离线评估脚本在 evaluate_test.py。  
- 基础单测在 test_config.py。

## 下面按你论文写作的角度，结合当前实现做“参数级”分析。

### 1) TextCNN 中 Embedding、卷积层与池化层的参数设置

| 组件 | 代码实现 | 参数设置 | 作用与影响 |
|---|---|---|---|
| Embedding 层 | textcnn_model.py | `nn.Embedding(vocab_size, embed_dim)` | 把词ID映射到稠密向量。`vocab_size`来自词表大小，`embed_dim`在训练配置中是 128（见 config.py）。 |
| 卷积层 | textcnn_model.py | `nn.Conv2d(in_channels=1, out_channels=100, kernel_size=(k, embed_dim))`，`k∈{2,3,4}` | 每种窗口大小用100个卷积核提取局部n-gram特征。因为卷积核宽度等于 `embed_dim`，所以它本质是在“时间维”做文本卷积。 |
| BN层 | textcnn_model.py | `nn.BatchNorm1d(100)`（每个分支一个） | 对每个卷积分支的100个通道做归一化，稳定训练。 |
| 激活 | textcnn_model.py | `F.relu` | 引入非线性，增强表达能力。 |
| 池化层 | textcnn_model.py | `F.max_pool1d(c, c.size(2))` | 对每个通道做“全局最大池化”（沿序列维取最大），每个分支输出 `(batch,100)`。 |
| 拼接 | textcnn_model.py | `torch.cat(..., dim=1)` | 3个分支拼接后得到 `(batch,300)`。 |
| Dropout | textcnn_model.py | `nn.Dropout(dropout)` | 默认0.5；训练时随机失活，降低过拟合。 |
| 分类层 | textcnn_model.py | `nn.Linear(300, num_classes)` | 300维特征映射到类别数。 |

### 重点澄清：你问的 Conv1d 与当前实现关系

当前代码不是直接写 `Conv1d`，而是“`Conv2d + squeeze`”的写法：

1. Embedding后张量是 `(batch, seq_len, embed_dim)`  
2. `unsqueeze(1)`后变 `(batch, 1, seq_len, embed_dim)`  
3. 用 `kernel_size=(k, embed_dim)` 做 `Conv2d`，相当于在序列维滑动、在词向量维一次性覆盖  
4. 再 `squeeze(3)` 变成 `(batch, 100, new_len)`，此时形式上就等价于典型文本 `Conv1d` 输出  
5. 最后 `max_pool1d` 做全局池化

所以论文里你可以写成“时间维一维卷积（实现上采用Conv2d等价写法）”。

### 卷积输出长度（可直接写进论文）

若序列长度为 $L$，卷积核高为 $k$，且 stride=1、padding=0，则  
$$
L' = L - k + 1
$$

本项目 `MAX_LEN=30` 时：
- $k=2 \Rightarrow L'=29$
- $k=3 \Rightarrow L'=28$
- $k=4 \Rightarrow L'=27$

每个分支再做全局最大池化，最终都压成100维，3个分支拼接为300维。
